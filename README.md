# 手機時間規劃 App｜GitHub Pages 上傳版

此資料夾只包含通用空白版，不含個人行程或待辦。請照以下順序操作：

1. 登入 GitHub.com。
2. 右上角按「＋」→「New repository」。名稱可輸入 `today-planner`；選「Public」→「Create repository」。
3. 在新儲存庫按「Add file」→「Upload files」。
4. 打開解壓後的這個資料夾，選取裡面的所有檔案（Ctrl+A），拖到 GitHub 上傳區。注意：要上傳檔案本身，讓 `index.html` 位於儲存庫最外層。
5. 下方按「Commit changes」。
6. 點儲存庫的「Settings」→左側「Pages」。在「Build and deployment」選「Deploy from a branch」；Branch 選 `main`，資料夾選 `/(root)`，按「Save」。
7. 等待 Pages 完成部署，再回到 Pages 設定頁按「Visit site」。網站網址會像 `https://你的帳號.github.io/today-planner/`。
8. 用手機開啟網址後加入主畫面：iPhone 用 Safari「分享」→「加入主畫面」；Android 用 Chrome「⋮」→「安裝應用程式」或「加到主畫面」。

個人行程請等網站在手機上開好後，再直接輸入。資料只存在該手機的瀏覽器，不會與電腦或 Google 日曆同步。
